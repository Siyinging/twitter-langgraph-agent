# Design 1-5 - 策略损益计算和可视化展示

## Requirements

### 核心功能需求

**1. 游戏化损益展示**
- 策略选择后立即显示盈亏结果，无需复杂图表
- 简化的盈亏计算：显示具体金额变化（如：+$3,000 / -$1,200）
- 直观的视觉反馈：绿色数字（盈利）、红色数字（亏损）
- 资金变化动画：账户余额平滑变化到新数值

**2. 策略解释和学习**
- 策略选择理由：为什么在这种市场情况下选择这个策略
- 结果解释：为什么盈利/亏损，帮助用户理解期权原理
- 替代策略对比：展示如果选择其他策略会有什么结果
- 学习要点：每次操作后的关键知识点总结

**3. 交互式功能**
- 价格滑块：拖动查看特定价格下的损益情况
- 悬浮提示：鼠标悬停显示精确的价格和损益数值
- 缩放功能：支持图表的放大缩小
- 价格区间调整：用户可自定义显示的价格范围

**4. 多维度分析**
- 到期损益：显示到期日当天的损益情况
- 当前损益：考虑时间价值的实时损益
- 希腊字母可视化：可选显示Delta、Gamma等变化曲线

### 性能要求

**响应性能：**
- 参数调整后图表更新时间 < 200ms
- 支持1000个价格点的平滑渲染
- 交互响应延迟 < 50ms

**数据处理：**
- 支持最多20个期权头寸的复合策略
- 自动优化价格点密度（重要区域密集，平缓区域稀疏）
- 内存占用控制在合理范围内

### 用户体验需求

**视觉设计：**
- 盈利区域：浅绿色填充
- 亏损区域：浅红色填充  
- 损益线：粗黑色线条
- 背景网格：浅灰色辅助线
- 响应式设计：适配不同屏幕尺寸

**中文本地化：**
- 所有标签和提示信息使用中文
- 数值格式本地化（千分位分隔符）
- 货币符号统一使用 ¥ 或 $

**2. 数据计算优化**
```typescript
// 智能价格点生成：关键区域密集采样
function generatePricePoints(
  currentPrice: number,
  breakevens: number[],
  range: [number, number]
): number[] {
  const points: number[] = [];
  const [minPrice, maxPrice] = range;
  
  // 基础采样点
  for (let i = 0; i <= 100; i++) {
    const price = minPrice + (maxPrice - minPrice) * (i / 100);
    points.push(price);
  }
  
  // 关键点位周围密集采样
  [...breakevens, currentPrice].forEach(keyPrice => {
    for (let offset = -keyPrice * 0.05; offset <= keyPrice * 0.05; offset += keyPrice * 0.01) {
      const price = keyPrice + offset;
      if (price >= minPrice && price <= maxPrice) {
        points.push(price);
      }
    }
  });
  
  return Array.from(new Set(points)).sort((a, b) => a - b);
}

// 批量损益计算
function calculateChartData(
  strategy: OptionStrategy,
  pricePoints: number[]
): ChartData {
  const pnlResults = optionEngine.calculateStrategy(strategy.positions, pricePoints);
  
  return {
    labels: pricePoints,
    datasets: [{
      label: '策略损益',
      data: pnlResults.map(result => result.totalPnL),
      borderColor: 'rgb(75, 192, 192)',
      backgroundColor: (context) => {
        const value = context.parsed.y;
        return value >= 0 ? 'rgba(34, 197, 94, 0.1)' : 'rgba(239, 68, 68, 0.1)';
      },
      fill: 'origin',
    }],
    annotations: generateAnnotations(pnlResults[0], pricePoints),
  };
}
```

**3. 性能优化策略**
- **防抖更新**：用户调整参数时使用debounce避免频繁计算
- **数据缓存**：缓存计算结果，相同策略避免重复计算
- **渐进渲染**：大数据量时使用requestAnimationFrame分批渲染
- **WebWorker**：复杂计算移到后台线程
