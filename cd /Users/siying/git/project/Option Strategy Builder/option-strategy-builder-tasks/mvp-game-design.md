# MVP游戏设计 - 期权策略大富翁

## 游戏核心设计

### 棋盘设计（12格简化版）
```
起点 → 牛市 → 震荡 → 熊市 → 突发事件 → 蝶式时刻
 ↑                                           ↓
学习                                      奖励格
 ↑                                           ↓
SignalPlus → 奖励格 → 突发事件 ← 震荡 ← 牛市 ←
```

**格子功能：**
1. **起点**：游戏开始，获得初始资金$10,000
2. **牛市**：BTC上涨场景，适合Long Call策略
3. **熊市**：BTC下跌场景，适合Long Put策略
4. **震荡**：价格横盘，适合Straddle/Iron Condor策略
5. **突发事件**：随机市场事件，考验应急反应
6. **蝶式时刻**：专门练习Butterfly策略
7. **奖励格**：获得额外资金或策略提示
8. **学习格**：期权知识小课堂
9. **SignalPlus格**：品牌介绍+引流机会

### 6种核心期权策略

**基础策略（前3种）：**
1. **Long Call（看涨买入）**
   - 适用：牛市行情
   - 风险：有限（权利金）
   - 收益：无限
   - 游戏表示：向上箭头+金币

2. **Long Put（看跌买入）**
   - 适用：熊市行情
   - 风险：有限（权利金）
   - 收益：高（价格跌至0）
   - 游戏表示：向下箭头+金币

3. **Covered Call（备兑看涨）**
   - 适用：温和上涨或横盘
   - 风险：机会成本
   - 收益：权利金收入
   - 游戏表示：盾牌+金币

**进阶策略（后3种）：**
4. **Straddle（跨式组合）**
   - 适用：高波动率，方向不明
   - 风险：双倍权利金
   - 收益：大幅波动时获利
   - 游戏表示：双向箭头

5. **Iron Condor（铁鹰式）**
   - 适用：低波动率，横盘整理
   - 风险：有限
   - 收益：有限但概率高
   - 游戏表示：老鹰图标

6. **Butterfly（蝶式组合）**
   - 适用：预期特定价格区间
   - 风险：有限
   - 收益：精确预测时最优
   - 游戏表示：蝴蝶图标

### 游戏流程设计

**单局游戏（15-30分钟）：**
1. **开始**：选择角色（初学者/进阶者），获得初始资金
2. **回合制**：掷骰子移动→遭遇市场情况→选择策略→查看结果
3. **策略选择**：根据市场情况从可用策略中选择
4. **实时反馈**：立即显示盈亏，更新资金
5. **学习时刻**：策略结果解释，为什么盈利/亏损
6. **进度追踪**：策略使用次数，解锁新策略
7. **游戏结束**：资金目标达成或回合数用完

**胜利条件：**
- 资金达到$50,000（5倍增长）
- 或完成20回合后资金最多
- 成功使用所有6种策略

**失败条件：**
- 资金低于$1,000
- 连续5次选择错误策略

### 市场情况库设计

**12种市场情况配置：**

1. **经典牛市**
   - 场景：BTC从$45,000涨至$50,000
   - 最优策略：Long Call
   - 权利金：$1,000，到期盈利：$4,000

2. **急跌熊市**
   - 场景：BTC从$50,000跌至$42,000
   - 最优策略：Long Put
   - 权利金：$1,200，到期盈利：$6,800

3. **横盘震荡**
   - 场景：BTC在$48,000±$1,000震荡
   - 最优策略：Iron Condor
   - 净权利金收入：$500

4. **突发暴涨**
   - 场景：利好消息，BTC单日涨10%
   - 最优策略：Straddle（提前布局）
   - 盈利：$3,000

5. **突发暴跌**
   - 场景：监管利空，BTC单日跌12%
   - 最优策略：Straddle（提前布局）
   - 盈利：$3,500

6. **蝶式精准预测**
   - 场景：BTC精确在$48,000到期
   - 最优策略：Butterfly
   - 最大盈利：$2,000

7. **温和上涨**
   - 场景：BTC缓慢从$46,000涨至$49,000
   - 最优策略：Covered Call
   - 权利金收入：$800

8. **温和下跌**
   - 场景：BTC缓慢从$50,000跌至$47,000
   - 最优策略：Protective Put
   - 保险成本：$600，避免损失：$2,400

9. **假突破上涨**
   - 场景：BTC突破$52,000后回落$48,000
   - 陷阱：Long Call会亏损
   - 最优策略：Iron Condor

10. **假突破下跌**
    - 场景：BTC跌破$44,000后反弹$48,000
    - 陷阱：Long Put会亏损
    - 最优策略：Straddle

11. **高波动率环境**
    - 场景：BTC日内波动±5%，连续多日
    - 最优策略：Short Straddle（卖出跨式）
    - 收入：波动率回归后获利

12. **低波动率环境**
    - 场景：BTC连续一周波动<1%
    - 最优策略：Long Straddle（买入跨式）
    - 等待：波动率扩张时获利
