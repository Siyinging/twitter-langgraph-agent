# Design 1 - 期权策略构建器

## Requirements

### 项目定位与核心价值

**项目目标：** 创建期权策略学习大富翁游戏，通过游戏化方式教育加密期权交易
**独特价值：** 游戏化学习体验，在娱乐中掌握期权策略，零风险实战演练
**目标用户：** 对加密期权感兴趣的新手和进阶用户
**产品性质：** 教育游戏 + SignalPlus平台引流工具
**商业目标：** 用户教育 → 品牌认知 → 引流转化到 t.signalplus.com

### 核心游戏功能需求

**1. 大富翁游戏机制 (Monopoly Game Engine)**
- 掷骰子移动：玩家轮流掷骰子在棋盘上移动
- 市场事件格子：不同格子触发不同的市场情况
- 策略选择：根据当前市场情况选择合适的期权策略
- 资金管理：游戏内虚拟资金，盈亏直接影响游戏进程
- 胜负判定：最终资金最多的玩家获胜

**1.1 市场情况设计 (Market Scenarios)**
- 牛市行情：适合做多策略（Long Call、Bull Spread）
- 熊市行情：适合做空策略（Long Put、Bear Spread）  
- 震荡行情：适合波动率策略（Straddle、Iron Condor）
- 突发事件：考验用户应急策略选择能力
- 蝶式时刻：专门练习Butterfly等复杂策略的场景

**1.2 期权策略教学 (Strategy Learning)**
- 策略库：Long/Short Call/Put、Straddle、Strangle、Butterfly、Iron Condor
- 情境匹配：每种市场情况推荐最佳策略
- 实时反馈：策略选择后立即显示盈亏结果
- 策略解释：简单易懂的策略原理和适用场景说明
- 进阶挑战：从基础策略逐步解锁复杂组合策略

**2. SignalPlus集成引流 (SignalPlus Integration)**
- 品牌露出：游戏界面显著展示SignalPlus品牌
- 数据来源：使用SignalPlus真实市场数据增强真实感
- 引流入口：游戏结束后引导用户访问 t.signalplus.com
- 操作手册：内置交易操作手册，桥接游戏和实盘交易
- 学习路径：游戏→手册→实盘的完整学习闭环

**3. MVP核心体验 (MVP Core Features)**
- 单人游戏：避免复杂的多人同步，专注策略学习
- 12格简化棋盘：快速游戏体验，单局15-30分钟
- 6种核心策略：覆盖常见交易场景
- 实时损益计算：直观的盈亏反馈
- 成就系统：鼓励用户学习不同策略

### 用户体验设计需求

**游戏化设计原则：**
- 趣味性优先：游戏体验胜过教学严肃性
- 渐进式学习：从简单策略逐步解锁复杂策略
- 即时反馈：操作后立即显示结果和解释
- 成就感设计：通过成就、排行榜激励学习

**视觉设计标准：**
- 游戏风格界面：卡通风格、明亮色彩
- 直观色彩体系：绿色(盈利)、红色(亏损)、蓝色(SignalPlus品牌)
- 移动端优先：主要在手机上游玩
- 品牌一致性：与SignalPlus品牌调性保持一致

**引流转化设计：**
- 自然引导：游戏过程中自然露出SignalPlus品牌和价值
- 软性转化：避免硬广，通过价值认知促进转化
- 学习路径：游戏→手册→实盘的完整转化路径
- 社交分享：支持分享游戏成绩，扩大影响力

### 技术与数据需求

**MVP技术栈要求：**
- 前端：React + TypeScript，移动端适配
- 后端：Python FastAPI，简单快速
- 数据：SignalPlus API + 简单缓存
- 部署：单体应用，快速上线

**游戏数据需求：**
- SignalPlus实时市场数据：增强游戏真实感
- 期权策略模板：预设6种核心策略的参数和逻辑
- 市场情况库：12种不同市场情况的配置
- 用户进度：游戏状态、成就、学习进度

**性能要求（MVP级别）：**
- 游戏响应时间 < 500ms（可接受的游戏体验）
- 支持并发用户 > 100（初期目标）
- 移动端流畅运行（主要使用场景）
- 离线模式：网络不佳时可用模拟数据继续游戏

**引流转化技术支持：**
- 数据统计：用户行为、游戏完成率、转化效果追踪
- A/B测试：不同引流策略的效果对比
- 分享功能：社交媒体分享，扩大传播
- 跟踪链接：精确统计从游戏到SignalPlus的转化

### 新手友好化设计

**游戏化教学方案：**
- 故事模式：包装成"期权交易大师成长记"的剧情
- 渐进解锁：完成基础策略后解锁复杂策略
- 实战演练：真实市场情况下的策略选择练习
- 错误引导：犯错时给出友善提示和正确引导

**概念简化和游戏化：**
- "Long Call" → "看涨买入"→ 游戏中表现为"市场向上箭头+金币"
- "蝶式期权" → "蝶式策略"→ 游戏中用蝴蝶图标表示
- "波动率" → "市场波动"→ 游戏中用震动效果表示
- "时间价值衰减" → "时间流逝"→ 游戏中用倒计时表示

**学习路径设计：**
1. 游戏引导：掷骰子→遇到市场情况→选择策略→看结果
2. 策略学习：通过游戏实践掌握6种核心策略  
3. 进阶挑战：复杂市场情况下的策略组合
4. 转化引流：游戏结束推荐SignalPlus实盘体验

## Solution

### 系统架构设计

**技术栈选择：**
- **前端：** React 18 + TypeScript + Vite
- **状态管理：** Zustand (轻量级，适合中等复杂度)
- **图表库：** Chart.js + react-chartjs-2 (实时性好，定制性强)
- **UI组件：** Tailwind CSS + Headless UI (快速开发，高度定制)
- **构建工具：** Vite (快速热重载，开发体验佳)

**部署架构：**
- **前端：** Vercel/Netlify (静态部署，CDN加速)
- **API服务：** Next.js API Routes (简化部署，无需独立后端)
- **数据获取：** Client-side API calls (减少服务器压力)

### 核心模块设计

**1. 期权计算引擎 (OptionEngine)**
```typescript
interface OptionPosition {
  id: string;
  type: 'call' | 'put';
  action: 'long' | 'short';
  strike: number;
  premium: number;
  quantity: number;
  expiry: Date;
}

interface PnLResult {
  totalPnL: number;
  maxProfit: number;
  maxLoss: number;
  breakevens: number[];
  positions: PositionPnL[];
}

class OptionEngine {
  calculateStrategy(positions: OptionPosition[], spotPrices: number[]): PnLResult[]
  findBreakevens(positions: OptionPosition[]): number[]
  calculateGreeks(position: OptionPosition, spot: number, volatility: number): Greeks
}
```

**2. 数据管理层 (DataService)**
- 实时价格获取：WebSocket连接Deribit/OKX
- 期权链数据：REST API定期更新
- 本地缓存：IndexedDB存储历史数据
- 错误处理：网络异常时使用模拟数据

**3. 策略模板系统 (StrategyTemplates)**
```typescript
interface StrategyTemplate {
  id: string;
  name: string;
  description: string;
  marketView: 'bullish' | 'bearish' | 'neutral';
  riskLevel: 'low' | 'medium' | 'high';
  positions: OptionPosition[];
  explanation: {
    scenario: string;
    profit: string;
    loss: string;
    tips: string[];
  };
}
```

## Tests

### 单元测试

**期权计算引擎测试：**
```typescript
describe('OptionEngine', () => {
  test('Long Call PnL calculation', () => {
    const position = { type: 'call', action: 'long', strike: 30000, premium: 1000 };
    const result = engine.calculatePnL([position], [25000, 30000, 35000]);
    expect(result[0].totalPnL).toBe(-1000); // 价格25000时亏损1000
    expect(result[1].totalPnL).toBe(-1000); // 价格30000时亏损1000  
    expect(result[2].totalPnL).toBe(4000);  // 价格35000时盈利4000
  });
  
  test('Breakeven calculation', () => {
    const positions = [{ type: 'call', action: 'long', strike: 30000, premium: 1000 }];
    const breakevens = engine.findBreakevens(positions);
    expect(breakevens).toContain(31000); // 盈亏平衡点
  });
});
```
