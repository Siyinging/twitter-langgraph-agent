# Design 1 - 期权策略构建器

## Requirements

### 项目定位与核心价值

**项目目标：** 创建面向加密货币期权新手的交互式学习工具
**独特价值：** 简化复杂期权概念，通过动态可视化和零风险模拟实现教育目标
**目标用户：** 加密货币期权零基础学习者
**产品性质：** 教育工具而非交易工具

### 核心功能需求

**1. 交互式构建界面 (Interactive Builder)**
- 模块化拖放操作：Long Call, Long Put, Short Call, Short Put
- 参数实时调整：标的物(BTC/ETH)、到期日、行权价、合约数量  
- 亚秒级响应：所有参数变化必须实时更新界面
- 视觉化画布：清晰展示期权组合结构

**1.1 期权链界面 (Option Chain Interface)**  
- 真实期权链显示：按到期日和行权价排列的期权合约
- 实时报价：买入价、卖出价、最后成交价、成交量
- 一键添加：直接从期权链点击添加到策略
- 灵活参数调整：可修改数量、查看隐含波动率
- 筛选功能：按单双周、价外价内、最小成交量筛选

**1.2 增强交互功能**
- 行权价选择器：基于实时数据的可用行权价列表
- 数量输入：支持小数和批量调整
- 实时计算：参数调整时即时显示权利金变化
- 持仓编辑：双击持仓可直接修改参数
- 快速操作：复制、删除、批量调整按钮

**2. 动态损益图 (Dynamic P&L Graph)**
- 核心功能：实时展示不同价格下的理论收益/亏损
- 关键标记：盈亏平衡点、最大收益、最大亏损（差异化色彩）
- 交互滑块：模拟标的物价格波动，观察损益变化
- 数据面板：保证金、盈亏平衡点、最大收益/亏损

**3. 预设策略模板库**
- 基础策略：买入看涨、买入看跌、备兑看涨、保护性看跌、跨式组合
- 通俗解释：每个策略的适用场景和市场预期
- 一键加载：模板可直接加载并允许参数修改

### 用户体验设计需求

**极简主义原则：**
- 去除复杂金融术语和冗余信息
- 核心功能突出，界面简洁明了
- 逐步引导：首次使用的气泡提示和操作指导

**视觉设计标准：**
- 直观色彩体系：绿色(盈利)、红色(亏损)
- 响应式设计：适配移动端和网页端
- 无障碍设计：考虑色盲用户的视觉体验

### 技术与数据需求

**核心数据要求：**
- 实时标的物价格（BTC/USDT, ETH/USDT）
- 期权链数据：行权价、买卖价、隐含波动率、未平仓量
- 历史价格数据：用于波动率计算和回测

**实时数据集成需求：**
- 数据源：Deribit、OKX、Binance 期权API
- 更新频率：价格数据1秒更新，期权链30秒更新
- 数据校验：确保行权价符合交易所标准间距
- 容错处理：网络异常时使用缓存数据和模拟数据
- 行权价生成：基于标的价格自动生成合理的行权价列表

**计算引擎需求：**
- 期权定价模型（Black-Scholes适配加密货币特性）
- 多头寸组合损益计算
- 希腊字母计算（Delta, Gamma, Theta, Vega）
- 实时数据处理和图表渲染

**性能要求：**
- 参数调整响应时间 < 100ms  
- 图表重绘时间 < 200ms
- 支持并发用户数 > 1000

### 新手友好化设计

**概念简化方案：**
- "盈亏平衡点" → "不赚不亏的价格"
- "最大亏损" → "最坏情况下的损失"
- "权利金" → "期权的购买成本"
- "行权价" → "执行期权的约定价格"

**教学流程设计：**
1. 从最简单的买入看涨开始
2. 逐步引入参数调整概念
3. 通过可视化展示风险收益关系
4. 最后学习组合策略构建

## Solution

### 系统架构设计

**技术栈选择：**
- **前端：** React 18 + TypeScript + Vite
- **状态管理：** Zustand (轻量级，适合中等复杂度)
- **图表库：** Chart.js + react-chartjs-2 (实时性好，定制性强)
- **UI组件：** Tailwind CSS + Headless UI (快速开发，高度定制)
- **构建工具：** Vite (快速热重载，开发体验佳)

**部署架构：**
- **前端：** Vercel/Netlify (静态部署，CDN加速)
- **API服务：** Next.js API Routes (简化部署，无需独立后端)
- **数据获取：** Client-side API calls (减少服务器压力)

### 核心模块设计

**1. 期权计算引擎 (OptionEngine)**
```typescript
interface OptionPosition {
  id: string;
  type: 'call' | 'put';
  action: 'long' | 'short';
  strike: number;
  premium: number;
  quantity: number;
  expiry: Date;
}

interface PnLResult {
  totalPnL: number;
  maxProfit: number;
  maxLoss: number;
  breakevens: number[];
  positions: PositionPnL[];
}

class OptionEngine {
  calculateStrategy(positions: OptionPosition[], spotPrices: number[]): PnLResult[]
  findBreakevens(positions: OptionPosition[]): number[]
  calculateGreeks(position: OptionPosition, spot: number, volatility: number): Greeks
}
```

**2. 数据管理层 (DataService)**
- 实时价格获取：WebSocket连接Deribit/OKX
- 期权链数据：REST API定期更新
- 本地缓存：IndexedDB存储历史数据
- 错误处理：网络异常时使用模拟数据

**3. 策略模板系统 (StrategyTemplates)**
```typescript
interface StrategyTemplate {
  id: string;
  name: string;
  description: string;
  marketView: 'bullish' | 'bearish' | 'neutral';
  riskLevel: 'low' | 'medium' | 'high';
  positions: OptionPosition[];
  explanation: {
    scenario: string;
    profit: string;
    loss: string;
    tips: string[];
  };
}
```

- 离线模式支持

## Tests

### 单元测试

**期权计算引擎测试：**
```typescript
describe('OptionEngine', () => {
  test('Long Call PnL calculation', () => {
    const position = { type: 'call', action: 'long', strike: 30000, premium: 1000 };
    const result = engine.calculatePnL([position], [25000, 30000, 35000]);
    expect(result[0].totalPnL).toBe(-1000); // 价格25000时亏损1000
    expect(result[1].totalPnL).toBe(-1000); // 价格30000时亏损1000  
    expect(result[2].totalPnL).toBe(4000);  // 价格35000时盈利4000
  });
  
  test('Breakeven calculation', () => {
    const positions = [{ type: 'call', action: 'long', strike: 30000, premium: 1000 }];
    const breakevens = engine.findBreakevens(positions);
    expect(breakevens).toContain(31000); // 盈亏平衡点
  });
});
```

**UI组件测试：**
```typescript
describe('StrategyBuilder', () => {
```
