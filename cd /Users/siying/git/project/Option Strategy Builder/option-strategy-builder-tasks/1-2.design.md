# Design 1-2 - 期权链界面和灵活参数操作

## Requirements

### 期权链界面需求

**核心显示要素：**
- 按到期日分组的期权合约列表
- 看涨期权(Call)和看跌期权(Put)并排显示
- 实时价格：买入价、卖出价、最后成交价
- 关键指标：隐含波动率、成交量、未平仓量
- 价内/价外状态标识

**交互功能需求：**
- 一键添加：点击任意期权直接添加到策略
- 快速筛选：按单双周到期、价内价外、最小成交量
- 排序功能：按行权价、成交量、隐含波动率排序
- 实时更新：价格和成交数据自动刷新

### 灵活参数操作需求

**持仓编辑功能：**
- 行权价调整：下拉选择器显示可用行权价
- 数量输入：支持整数和小数（0.1, 0.5, 1, 2等）
- 到期日切换：选择不同到期日的合约
- 期权类型转换：Call/Put 和 Long/Short 切换

**实时计算反馈：**
- 权利金实时更新：参数调整时即时显示成本变化
- 保证金计算：做空期权的保证金需求显示
- 影响分析：显示参数调整对整体策略的影响

**批量操作功能：**
- 多选功能：可同时选择多个持仓进行批量操作
- 比例调整：按比例放大或缩小持仓规模
- 复制粘贴：快速复制相似的期权头寸
- 模板保存：将当前参数保存为个人模板

### 数据准确性需求

**行权价生成规则：**
- BTC期权：以500/1000为间距（根据价格区间）
- ETH期权：以50/100/200为间距（根据价格区间）
- 动态调整：基于当前标的价格自动生成合理范围
- 交易所同步：确保行权价与主流交易所一致

**价格数据要求：**
- 实时性：延迟不超过3秒
- 准确性：与交易所数据误差<1%
- 完整性：包含所有活跃合约的完整数据
- 历史记录：保留最近24小时的价格变动历史

## Solution

### 期权链组件设计

**OptionChain 主组件架构：**
```typescript
interface OptionChainProps {
  underlying: 'BTC' | 'ETH';
  selectedExpiry: Date;
  onAddOption: (option: OptionContract) => void;
  currentPrice: number;
}

interface OptionChainData {
  expiry: Date;
  calls: OptionContract[];
  puts: OptionContract[];
  strikes: number[];
}
```

**OptionRow 行组件设计：**
```typescript
interface OptionRowProps {
  strike: number;
  callContract?: OptionContract;
  putContract?: OptionContract;
  currentPrice: number;
  onSelectOption: (contract: OptionContract, action: 'buy' | 'sell') => void;
}
```

### 参数编辑界面设计

**PositionEditor 组件：**
```typescript
interface PositionEditorProps {
  position: OptionPosition;
  availableStrikes: number[];
  availableExpiries: Date[];
  onUpdate: (updates: Partial<OptionPosition>) => void;
  onDelete: () => void;
}
```

**核心编辑功能：**
1. **StrikePicker**: 可用行权价的下拉选择器
2. **QuantityInput**: 支持小数的数量输入框
3. **ExpirySelector**: 到期日选择器
4. **TypeToggle**: Call/Put 和 Long/Short 切换器

### 实时数据流架构

**数据更新流程：**
1. **WebSocket连接**: 建立与数据源的实时连接
2. **数据解析**: 解析期权链和价格数据
3. **状态更新**: 更新Zustand store中的数据
4. **UI刷新**: 触发组件重新渲染

**数据管理策略：**
```typescript
interface OptionChainStore {
  chainData: Record<string, OptionChainData[]>;
  currentPrices: Record<string, number>;
  lastUpdate: Date;
  
  updateChainData: (underlying: string, data: OptionChainData) => void;
  updatePrice: (underlying: string, price: number) => void;
  getAvailableStrikes: (underlying: string, expiry: Date) => number[];
}
```

### 响应式设计考虑

**桌面端优化：**
- 期权链占用70%宽度，参数面板30%
- 支持键盘快捷键操作
- 鼠标悬停显示详细信息

**移动端适配：**
- 期权链和参数面板上下堆叠
- 滑动查看更多期权合约
- 触控优化的按钮和输入框

### 性能测试指标

**渲染性能：**
- 期权链加载时间 < 500ms
- 参数调整响应时间 < 100ms
- 大量数据渲染流畅度 > 30fps

**内存使用：**
- 期权链数据缓存 < 10MB
- 组件内存占用稳定
- 无内存泄漏
