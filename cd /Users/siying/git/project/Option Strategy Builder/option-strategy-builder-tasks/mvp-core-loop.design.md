# Design: MVP核心游戏循环

## Requirements

### 核心需求
用户希望重新设计加密期权大富翁游戏，要求专注于：
1. **核心游戏循环**：简化但完整的回合制游戏机制
2. **基础SignalPlus集成**：市场数据展示和学习资源链接
3. **教育价值最大化**：通过游戏学习金融投资基础知识
4. **MVP快速实现**：2-3周内可完成的精简版本

### 功能边界
**包含功能：**
- 12格精简棋盘（降低复杂度）
- 6种核心格子类型（投资、事件、决策）
- 基础虚拟资金管理
- 左侧SignalPlus市场面板
- 简单进度保存

**不包含功能（后续版本）：**
- 多人对战模式
- 复杂期权策略模拟
- 实时API数据集成
- 移动端原生应用

## Solution

### 1. 核心游戏循环设计

#### 1.1 回合流程
```
开始回合 → 投掷骰子 → 移动棋子 → 触发格子事件 → 玩家决策 → 处理结果 → 更新状态 → 结束回合
```

**详细步骤：**
1. **开始回合**：显示当前回合数、玩家状态
2. **投掷骰子**：1-6点随机数，带动画效果（0.8秒）
3. **移动棋子**：沿棋盘顺时针移动，动画时间1秒
4. **触发事件**：根据格子类型展示对应界面
5. **玩家决策**：10秒倒计时，超时自动选择默认选项
6. **处理结果**：执行决策后果，更新资金/资产
7. **更新状态**：刷新UI显示，检查游戏结束条件
8. **结束回合**：自动保存进度，准备下一轮

#### 1.2 游戏状态管理
```javascript
const GameState = {
  // 基础信息
  roundNumber: 1,
  maxRounds: 50,
  gameStatus: 'playing', // playing, paused, ended
  
  // 玩家状态

    name: 'Trader',
    position: 0,         // 当前位置 (0-11)
    cash: 1000,          // 现金
    assets: {},          // 持仓资产

  },
  
  // 市场数据

    btcPrice: 43250,

    volatility: 0.65,
    sentiment: 'neutral' // bullish, bearish, neutral
  },
  
  // 游戏历史
  history: []            // 交易记录
}
```

### 2. 12格精简棋盘设计

#### 2.1 格子布局（3×4矩形）
```
┌─────────┬─────────┬─────────┬─────────┐
│ 1:START │ 2:市场  │ 3:BTC   │ 4:决策  │
├─────────┼─────────┼─────────┼─────────┤
│12:信号站│         │         │ 5:ETH   │
├─────────┤  中央   │  信息   ├─────────┤
│11:事件  │  显示   │  面板   │ 6:风险  │
├─────────┼─────────┼─────────┼─────────┤
│10:奖励  │ 9:对冲  │ 8:新闻  │ 7:蓝筹  │
└─────────┴─────────┴─────────┴─────────┘
```

#### 2.2 格子详细设计

**投资资产区 (4格)：**
- **格子3 - BTC矿场**：购买成本$200，每回合收益$15
- **格子5 - ETH DeFi**：购买成本$150，每回合收益$12  
- **格子7 - 蓝筹ETF**：购买成本$100，每回合收益$8
- **格子12 - SignalPlus股份**：购买成本$300，每回合收益$20

**市场事件区 (4格)：**
- **格子2 - 市场机会**：随机利好事件，资产价值+10%
- **格子6 - 风险警告**：随机风险事件，可能损失5-15%
- **格子8 - 突发新闻**：基于实际新闻的市场影响模拟
- **格子11 - 黑天鹅**：低概率高影响事件

**策略决策区 (2格)：**
- **格子4 - 投资顾问**：花费$20获得下3回合市场提示
- **格子9 - 风险对冲**：花费$30购买保险，免疫下次损失

**特殊功能区 (2格)：**
- **格子1 - 起始点**：每经过获得$50基础收入
- **格子10 - 奖励池**：随机获得$20-100奖金

### 3. 决策机制设计

#### 3.1 决策界面统一结构
```html
<div class="decision-panel">
  <div class="header">
    <h3>{{event.title}}</h3>
    <div class="timer">⏱️ {{countdown}}秒</div>
  </div>
  
  <div class="content">
    <p class="description">{{event.description}}</p>
    <div class="market-info">
      💰 现金: ${{player.cash}}
      📊 总价值: ${{player.netWorth}}  
    </div>
  </div>
  
  <div class="options">
    <!-- 1-3个选项按钮 -->
    <button class="option-btn">{{option.text}}</button>
  </div>
</div>
```

#### 3.2 决策复杂度分级
- **简单决策（70%）**：是/否选择，如买入/观望
- **中等决策（25%）**：3个选项，包含成本收益分析
- **复杂决策（5%）**：多步骤决策，用于教学关键概念

### 4. 虚拟资金管理

#### 4.1 资金来源
- **起始资金**：$1000
- **回合收入**：每经过起始点+$50
- **资产收益**：持有资产的每回合分红
- **事件奖励**：正面事件的现金奖励

#### 4.2 支出项目
- **资产购买**：购买投资标的
- **服务费用**：投资顾问、保险等
- **事件损失**：负面事件造成的亏损
- **交易手续费**：买卖资产的0.1%费用

#### 4.3 破产机制
- **破产条件**：现金+资产总价值 < $50
- **救助机制**：允许"借贷"$200继续游戏（利息$5/回合）
- **游戏结束**：连续破产3次或完成50回合

### 5. 用户体验设计

#### 5.1 新手引导
1. **第1回合**：展示界面各部分功能
2. **第2回合**：演示决策流程和倒计时
3. **第3回合**：解释资产购买和收益机制
4. **第5回合**：介绍SignalPlus学习资源

#### 5.2 反馈机制
- **即时反馈**：决策结果立即显示，带数字动画
- **进度反馈**：经验值条、等级提升动画
- **成就提示**：达成里程碑时的庆祝效果
- **学习提示**：关键概念的教育性弹窗

测试步骤：

5. 做出决策，验证结果计算

- 每步操作响应时间 < 200ms

- 数据计算准确无误
- UI状态同步及时

### 游戏性测试

#### G1: 学习效果验证
```
测试方法：
1. 招募10名测试用户（金融知识新手）
2. 游戏前后进行知识测试
3. 记录游戏过程中的决策质量变化
4. 收集用户反馈和建议

评判标准：
- 知识测试成绩提升 > 20%
- 游戏内决策准确率提升 > 15%
- 用户满意度评分 > 4.0/5.0
- 完成率 > 80%
```

#### G2: 游戏平衡性测试
```
测试指标：
- 平均游戏时长：15-25分钟
- 破产率：< 20%
- 最高资产价值：$5000-$15000
- 决策超时率：< 10%

调整机制：
- 如果破产率过高，增加基础收入
- 如果游戏过于容易，提高风险事件概率
- 如果决策超时频繁，延长倒计时
```
